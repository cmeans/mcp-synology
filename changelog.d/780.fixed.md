- **Installs no longer get PyYAML 6.0.4** (#780): PyYAML 6.0.4 reverses which map wins in a `<<: [*a, *b]` merge (yaml/pyyaml#953, not yet fixed upstream), so on an install that had it, a config merging a list of maps loaded other values than the YAML spec gives, and the advice the error for two `<<` keys gives changed the result instead of keeping it. mcp-synology now requires `pyyaml>=6.0.1,!=6.0.4`; upgrading mcp-synology replaces 6.0.4 with an earlier release, and a fixed later release is taken — closes #779
