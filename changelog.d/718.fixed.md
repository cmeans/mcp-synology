- **`get_dir_size` and `list_files` end the call when the NAS doesn't answer their check** (#718): the check before a request follows #704's one rule. `get_dir_size` started its DirSize task after a proxy's 502 on its `getinfo` check and reported a size as if the check had passed; `list_files`, when the `getinfo` that tells a file from a missing path (DSM answers List's 408 for both) failed or timed out, still replied "doesn't exist", which it hadn't checked. Now a transport error or timeout, a proxy's error status, a reply that isn't DSM's or a refused re-login ends the call with nothing started. In `list_files`, a check that can't tell (a DSM error code, an entry it can't read, a malformed reply) says what DSM said: `List files failed: DSM says /video/x doesn't exist (DSM error 408), and whether it's a file couldn't be checked.`; it now reads the check through `folder_kind`, as its 401 branch does. In `get_dir_size`, a DSM error code on the check still lets DirSize run, its status mapped as before. — closes #705
