- **`get_photo`'s Camera and Location lines quote a value holding their separators** (#722): the camera model, lens, aperture, exposure and ISO are EXIF text from the file, which whoever made it chose, and the line joined them with ` · ` as they were, so a camera model `Canon · lens EF 50mm · aperture F1.0` showed two lenses and two apertures, the first of each fake. Each value is now JSON-quoted when it could read as the line's structure: when it holds ` · `, also with the space beside it (`lens · F1.0`), is `—` (or a labeled placeholder, `aperture —`, where the slot has no label), or would be quoted as a Photos name is (#700: a quote, a backslash, padding); the unlabeled aperture and exposure are quoted in any form but DSM's own (`F1.5`, `1/30 s`), so `"2.8 (max)"` now shows quoted, and so is a camera model that reads as another slot (`ISO 3200`, `F1.0`, `lens EF 50mm`). A Location part (a coordinate or an address name) follows the same rule with `, ` and ` · ` — closes #710
