- **`create_folder` said "Insufficient filesystem permissions" for a name that was already taken** (#751): DSM answers a folder that exists (with `force_parent=false`) or a file at the path with error 1100 and puts the real cause, 414 "File already exists", in its reply's `errors`, which the tools ignored. Now, when DSM's reply to a request names the cause of one of File Station's wrapper errors (900, 1000, 1001, 1002, 1100, 1200; seen for 1100 and 1200), the error names it and takes its advice and retry flag; `create_folder` reports the taken name as `already_exists`, and `rename` reports a taken name without its extra lookup. The "already exists" advice no longer tells tools without an `overwrite` parameter to use it, and 900, 1100 and 1101 read as Synology's guide defines them ("Failed to delete", "Failed to create the folder", "Too many folders in the parent folder") — closes #749 and #726
