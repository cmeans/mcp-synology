- **CHANGELOG entries are fragments in `changelog.d/`, assembled by towncrier at release** (#732): each PR writes its entry as a file named `<PR>.<added|changed|fixed>.md` instead of editing `## Unreleased`, so merges no longer leave every other open PR with a CHANGELOG conflict and a push that dismisses its approval. `scripts/changelog_fragments.py check` (CI job `changelog`) requires a fragment named for the PR's own number, unless the PR has the `no changelog` label, and checks the names, content and `CHANGELOG.md`'s layout; `check_release.py` refuses a release with fragments left; Dependabot's PRs get a fragment; the release steps run `towncrier build` — closes #731
